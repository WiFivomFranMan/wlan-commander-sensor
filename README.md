# WLAN Commander sensor image — downloads

Images for the FriendlyElec NanoPi Zero2 Wi-Fi 7 capture sensor.

**https://wifivomfranman.github.io/wlan-commander-sensor/**

Grab a build from [Releases](https://github.com/WiFivomFranMan/wlan-commander-sensor/releases).
Each one ships as an `.img.xz` with a `.sha` checksum and a `.build-info` file recording the
Armbian commit and kernel branch it came from.

This repository holds the download page only. The build tree is not published.
The kernel is stock [Armbian](https://github.com/armbian/build) at the commit named in
`.build-info`, and the configuration it was built with is in the image at `/boot/config-*`.
